# Surface: demo/index.html

Scope: a projected, keyboard-stepped live-demo page for the hackathon judging (3 minutes, 7 scenes), also linkable from the README. Mode: persuade. English only. Single static HTML, offline, fonts embedded.

Audience: Cline, Composio and Parallel judges in a bright event room, reading a projector from 5-10 m. Job: in three minutes, believe Olav is real, open, and safe: it reads real data, plans around real life, code blocks bad plans, nothing ships without approve.

Proof/content: the author's real Garmin data and real tool outputs from Oct 19 2026 (see PRODUCT.md Evidence). Guardrail violations are the verbatim output of check_plan(). Chat wording is condensed and translated from Portuguese and labelled as a replay.
